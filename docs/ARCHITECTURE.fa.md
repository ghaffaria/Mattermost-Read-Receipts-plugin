# معماری

سرور برای هر جفت پیام/کاربر اولین زمان مشاهدهٔ صریح را در PostgreSQL نگه می‌دارد. دریافت پیام و cursor کانال مبنای حدس خوانندگان نیست. احراز هویت و عضویت کانال روی خواندن و نوشتن رسید اعمال می‌شوند؛ درخواست عضو نبودن در خصوصی403 می‌گیرد.

کنترلر وب به فوکوس پنجره و فعال‌بودن صفحه وابسته است و کانال و ترد را پوشش می‌دهد. قطع نمایش یا فوکوس، زمان قبلی را حذف می‌کند. تیک از تاریخچهٔ واقعی سرور ساخته می‌شود.

اندروید از ClientMix، کنترلر مستقل هر فهرست و snapshot فوکوس native استفاده می‌کند. حد نمایش۵۰٪ کوچک‌تر ارتفاع ردیف و viewport قابل‌استفاده برای۲۰۰۰میلی‌ثانیهٔ پیوسته است. سربرگ، composer، صفحه‌کلید و نوار خوانده‌نشده از فهرست کنار گذاشته می‌شوند. پیشنهادهای تایپ و پوشش تماس ثبت رسید را موقتاً متوقف می‌کنند. دریافت تاریخچه هر۳ثانیه، تنظیمات هر۱۵ثانیه و batch حداکثر۲۰۰شناسه است. پاسخ دیرهنگام نشست قبلی نادیده گرفته می‌شود؛ retry درخواست ثبت، مشاهدهٔ تازه لازم دارد.

اصلاح شبکه، initializeهای هم‌زمان را یکی می‌کند، اتصال قبلی را پیش از انتظار پاسخ close بازنشسته می‌کند و خطای ساخت client را بازیابی می‌کند. رویدادهای native شناسهٔ نسل دارند؛ callback اتصال قدیمی به اتصال تازه نسبت داده نمی‌شود. کنترل سخت‌گیرانهٔ sequence و اعتبارسنجی TLS حفظ شده‌اند. localhost و نام میزبان داخلی معتبر پشتیبانی می‌شوند.

سورس Android به شکل patch کنترل‌شده نسبت به v2.46.0 ارائه شده است. APK تغییر schema سرور لازم ندارد. سورس سرور و وب در server و webapp قرار دارد. کلید امضا و تنظیمات اجرا جزو ریپو نیستند.
